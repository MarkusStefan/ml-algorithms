# ml-algorithms
Implementation of popular machine learning algorithms in native python + numpy + scipy

- Naive and simple to understand implementations are provided for educational purposes. 
- The `scikit-learn` API has been used as a reference for the implementation of these algorithms due to its convenient and consistent API.
- The code is not optimized for performance.
